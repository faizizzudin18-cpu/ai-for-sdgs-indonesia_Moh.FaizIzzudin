TENTANG PROYEK

Mengapa Website Ini Ada

Catatan dari Tim Redaksi

Inisiatif ini lahir dari kegelisahan sederhana: dalam diskursus publik Indonesia tentang AI, dua narasi dominan adalah ketakutan ("AI akan mengganti pekerjaan kita") dan utopianisme ("AI akan menyelesaikan semua masalah"). Padahal di antara dua kutub itu, ada ruang luas yang lebih menarik dan lebih relevan: bagaimana AI, sebagai alat, sedang digunakan secara konkret untuk menyelesaikan masalah nyata di Indonesia hari ini.

Website ini adalah upaya kecil untuk memetakan ruang itu. Dengan fokus pada 17 Sustainable Development Goals, kami mendokumentasikan inisiatif AI yang sedang berjalan — dari startup di Bandung sampai laboratorium riset di Yogyakarta, dari Kementerian sampai NGO lapangan.

Kami menyebut ini "inisiatif open-source" karena: (1) semua kode website ini terbuka di GitHub, (2) data yang kami gunakan dapat diunduh dan diverifikasi, (3) kami menerima kontribusi dari siapa pun yang ingin menambah studi kasus, mengoreksi data, atau menyempurnakan analisis.

Indonesia akan mencapai SDGs — atau tidak — pada 2030. AI tidak akan menjadi penentu tunggal. Tapi kalau dipakai dengan bijak, AI bisa mempercepat pencapaian yang sudah berjalan, dan menerangi area yang selama ini tertinggal.

"Data yang baik adalah fondasi kebijakan yang baik. Kami percaya bahwa mendokumentasikan dan membuka data adalah bentuk advokasi paling tahan lama."

Prinsip Editorial

01

Berbasis data, bukan narasi

Setiap klaim didukung dengan sumber yang dapat diverifikasi. Kami membedakan dengan tegas antara data empiris dan proyeksi atau estimasi.

02

Kritis, bukan selebrasi

Setiap studi kasus menyertakan tantangan dan kritik. AI bukan solusi ajaib — dan kami tidak menulis seperti itu.

03

Terbuka dan dapat diaudit

Semua data tersedia untuk diunduh. Kode sumber website terbuka. Kami menyambut koreksi dan pembaruan dari komunitas.

04

Berpihak pada yang terpinggirkan

Kami secara aktif mencari studi kasus dari daerah 3T, komunitas adat, dan kelompok yang historis tidak terwakili dalam narasi teknologi Indonesia.

Cara Berkontribusi

Proyek ini terbuka untuk kontribusi dalam bentuk apapun — dari koreksi data, penambahan studi kasus, hingga perbaikan desain atau kode. 

# Clone repository
git clone https://github.com/[username]/ai-for-sdgs-indonesia.git

# Masuk ke direktori
cd ai-for-sdgs-indonesia

# Buka di browser
open index.html

# Untuk kontribusi:
# 1. Fork repository
# 2. Buat branch baru
git checkout -b fitur-baru

# 3. Commit perubahan
git commit -m "Tambah studi kasus X"

# 4. Push ke fork Anda
git push origin fitur-baru

# 5. Buka Pull Request di GitHub

Jenis kontribusi yang kami sambut:

  • Studi kasus baru: proyek AI for SDGs yang belum terdokumentasi
  • Koreksi data: jika ada angka yang tidak akurat atau sudah usang
  • Terjemahan: kami berencana menyediakan versi bahasa Inggris
  • Aksesibilitas: peningkatan WCAG untuk pengguna dengan disabilitas
  • Visualisasi data: chart atau peta baru yang memperkaya analisis
